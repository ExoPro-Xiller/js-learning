=> Projects

The repository contains projects created while learning JavaScript.

=> Multi-User Account System

A vanilla JavaScript authentication-style system supporting multiple users.

Features include:

* Account creation
* Login/logout
* Duplicate-account prevention
* Current-user tracking
* Persistent data with `localStorage`
* Account-specific data
* Dashboard functionality
* Account deletion

The project has also gone through multiple refactors as my understanding of JavaScript improved.
